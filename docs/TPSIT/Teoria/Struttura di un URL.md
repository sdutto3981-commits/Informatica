# Struttura di un URL

Le parti principali di un URL:
Un URL è una sequenza di elementi che lavorano insieme pr locallizare una risorsa internet https://www.esempio.com/blog/articoli?id=123#intro

1. **Protocollo**
	- indica il metodo di comunicazione
	- https:// che indica una connessione sicura
2. **Host**
	- è il nome del server o dominio che ospita la risorsa
	- Composto:
		- **Sottodominio**: www
		- **Dominio di secondo livello** esempio
		- **Dominio di primo livello** .com
3. **Percorso**
	- Indica la posizione della risorsa all interno del host
	- /blog/articoli
4. **Query**
	- sequenza di parametri per filtrare o personalizzare una risorsa
