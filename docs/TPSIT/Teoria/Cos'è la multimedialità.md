# Cos'è la multimedialità

Combinazione di più media diversi per un unico sistema Multi=molti, Media= mezzi di comunicazione

#### Caratteristiche

- Integrazione
	- Diversi media che lavorano insieme
- Interattività
	- L'utente può interagire con i contenuti
- Sincronizzazione
	- Condivisione temporanea tra media
- Digitalizzazione
	- Tutti i media convertiti in formato digitale
