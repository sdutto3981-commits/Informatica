# Introduzione Git

Serve per archiviare in modo ordinato il codice con diverse versione per più persone.

Più specificamente serve per il controllo versione è un sistema che controlla le modiche apportate a un file o ad un insieme di essi in modo da poter richiamare in seguito le versioni.

Avendo più programmatori che partecipano ad esso si psso sviluppare errori quando per esempio si lavora ad una nuova funzionalità ma essa rompe il sistema allora si può usare Git per tornare indietro alla versione precedente alla modifica.

Mentre Git è un sistema distribuito (DVCS) che non si limita a controllare l'ultima versione del file oppure di un gruppo di essi ma mantiene una cronologia della repository quindi essa può anche essere scaricata localmente e modifica e successivamente caricarla in modo che git possa salvarlo come nuova versione
