# Consigli per il profilo GitHub

Un buon profilo deve rendere comprensibile ciò che sai fare senza esagerare le competenze.

- Scrivi una breve descrizione accurata dei linguaggi e degli strumenti che usi davvero.
- Fissa pochi repository rappresentativi e mantieni README con obiettivo, requisiti, avvio e screenshot quando utili.
- Includi istruzioni riproducibili e licenza quando appropriato.
- Usa messaggi di commit chiari, issue e pull request leggibili.
- Rimuovi credenziali, token, indirizzi privati, dati personali e file di configurazione sensibili.
- Distingui progetti completati, prototipi e lavori in corso.

La qualità dei repository e la chiarezza delle istruzioni sono più utili di un gran numero di progetti vuoti o copiati senza spiegazione.
