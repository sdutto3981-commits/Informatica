# Tutti colori HTML

In HTML i colori sono specificati o per nome oppure per RGB, HEX, HSL o HSLA

#### Background Color

Possiamo impostare il colore di sfondo per gli elementi HTML

```html
<h1 style="background-color:DodgerBlue;">Hello World</h1>
<p style="background-color:Tomato;">Lorem ipsum...</p>
```

#### Text Color

Possiamo impostare il colore del testo
```html
<h1 style="color:Tomato;">Hello World</h1>
<p style="color:DodgerBlue;">Lorem ipsum...</p>
<p style="color:MediumSeaGreen;">Ut wisi enim...</p>
```

#### Border Color

Possiamo impostare il colore dei bordi
```html
<h1 style="border:2px solid Tomato;">Hello World</h1>
<h1 style="border:2px solid DodgerBlue;">Hello World</h1>
<h1 style="border:2px solid Violet;">Hello World</h1>
```

#### Color Values

In HTML i colori sono specificati anche RGB HEX HSL RGBA HSLA

per esempio:
- `rgb(255, 99, 71)`

- `#ff6347`

- `hsl(9, 100%, 64%)`

Questi tre sono tutti lo stesso colore mentre invece con RGBA e HSLA ce un canale Alpha che gestisce la trasparenza
