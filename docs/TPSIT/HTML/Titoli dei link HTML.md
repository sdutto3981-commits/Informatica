# Attributo `title` nei collegamenti

L'attributo globale `title` può fornire informazioni supplementari su un collegamento o un altro elemento.

```html
<a href="manuale.pdf" title="Manuale tecnico in PDF, 2 MB">
  Scarica il manuale tecnico
</a>
```

Il testo tra i tag è il nome accessibile principale del link. `title` è soltanto un'informazione aggiuntiva: non sostituisce un testo descrittivo e non deve essere l'unico modo per comunicare informazioni essenziali, perché non tutti i dispositivi o utenti lo rendono disponibile allo stesso modo.

Preferisci scrivere direttamente un'etichetta comprensibile. Per immagini usa `alt` per descrivere il contenuto o la funzione, non `title` come sostituto del testo alternativo.
