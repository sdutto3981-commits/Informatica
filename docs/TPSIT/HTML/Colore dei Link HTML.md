# Colore dei Link HTML

Possiamo usare lo style per fare sembrare il link come un pulsante

```css
<style>
a:link, a:visited {  background-color: #f44336;
  color: white;
  padding: 15px 25px;
  text-align: center;
  text-decoration: none;
  display: inline-block;}

a:hover, a:active {  background-color: red;}
</style>
```
