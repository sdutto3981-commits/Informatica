# Link per creare segnalibri HTML

Un può essere utile quando la pagina è veramente lunga  per creare un segnalibro prima di tutto lo creiamo e poi aggiungiamo il link ad esso una volta che il link sarà cliccato la pagina scorrerà sino ad esso.

```html
<h2 id="C4">Chapter 4</h2>
```

Questo è il segnalibro con il suo id

```html
<a href="#C4">Jump to Chapter 4</a>
```

Questo è il link con l'id a segnalibro
