# Attributo target HTML

Quando premiamo un collegamento quella pagina viene aperta direttamente sulla stessa pagina del browser per cambiare ciò usiamo il tag `target` che specifica dove aprire il collegamento

Può avere i seguenti valori:
- `_self` apre il collegamento nella stessa finestra da cui abbiamo cliccato
- `_blanck` apre il collegamento in una nuova finestra
- `_parent` apre il documento nel frame padre
- `_top` Apre il collegamento all'interno del corpo della finestra

##### forms

`<form action="/action_page.php" target="_blank">`
