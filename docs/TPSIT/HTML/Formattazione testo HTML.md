# Formattazione testo HTML

Esistono diversi elementi per la formattazione del testo in html
- `<b>` Testo in grassetto
- `<strong>` Testo importante
- `<i>` Testo in corsivo
- `<em>` Testo enfatizzato
- `<mark>` Testo evidenziato
- `<small>` Testo più piccolo
- `<del>` Testo barrato
- `<ins>` Testo sottolineato
- `<sub>` Testo a pedice
- `<sup>`  Testo superiore
