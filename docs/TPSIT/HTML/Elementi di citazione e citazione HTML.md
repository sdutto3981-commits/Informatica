# Elementi di citazione e citazione HTML

#### Elemento `<blockquote>`

Definisce una sezione citata da un altra fonte di cui inseriremo il link

#### Elemento `<q>`

Definisce una citazione breve

#### Elemento `<abbr>`

Definisce un abbreviazione o un acronimo contrassegnare le abbreviazioni fornisce informazioni utili al browser

#### Elemento `<address>`

Definisce  le informazioni di contatto del proprietario del documento o dell'articolo

#### Elemento `<cite>`

Definisce l'autore di un opera creativa
