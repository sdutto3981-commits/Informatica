# Colori, font e dimensioni in CSS

```css
body {
  color: #222;
  background-color: #fff;
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
}
```

- `color` definisce il colore del testo.
- `background-color` definisce lo sfondo.
- `font-family` imposta le famiglie di caratteri preferite.
- `font-size` definisce la dimensione del testo; `rem` è relativa alla dimensione del font radice.
- `line-height` regola l'altezza della riga.

Controlla sempre il contrasto tra testo e sfondo. Vedi [unità, colori e tipografia](../CSS/Unità%20colori%20e%20tipografia%20CSS.md).
