# HTML-Colori Font e Dimensioni CSS

Con CSS possiamo definire i colori i caratteri le dimensioni con:
- La proprietà CSS ==color== definire il colore del testo
- La proprietà CSS ==font-family== definisce il carattere del testo
- La proprietà CSS ==font-size== definisce la dimensione del testo
