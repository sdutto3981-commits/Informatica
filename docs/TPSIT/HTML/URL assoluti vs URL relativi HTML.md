# URL assoluti vs URL relativi HTML

URL assoluti nel attributo `href` è un interno indirizzo web

URL relativi sono link a una pagina all'interno dello stesso sito  ed è senza https://

```html
<h2>Absolute URLs</h2>
<p><a href="https://www.w3.org/">W3C</a></p>
<p><a href="https://www.google.com/">Google</a></p>

<h2>Relative URLs</h2>
<p><a href="html_images.asp">HTML Images</a></p>
<p><a href="/css/default.asp">CSS Tutorial</a></p>
```
