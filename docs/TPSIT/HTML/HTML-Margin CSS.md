# `margin` in CSS

`margin` definisce lo spazio esterno al bordo di un elemento, utile per separarlo dagli altri elementi.

```css
.card {
  margin: 1rem 0;
}
```

Con una dichiarazione a quattro valori l'ordine è alto, destra, basso, sinistra. I margini verticali di elementi a blocco possono collassare in alcune condizioni. Il margine è diverso dal `padding`, che crea spazio interno tra contenuto e bordo.

Consulta [box model](../CSS/Box-Model.md).
