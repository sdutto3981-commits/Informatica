# Che cos'è una Virtual Machine


Lo scopo della virtualizzazione è quello di lavorare con un sistema operativo diverso a quello installato nel computer abbiamo quindi bisogno di una macchina virtuale.

Una macchina virtuale è una  macchina che simula un pc reale sulla quale poter installare un sistema operativo diverso.

Questo ci permette anche di personalizzare le caratteristiche della macchina virtuale che vogliamo usare

Ci sono diversi software per esso il piu famoso è:
- VMware
- Virtual Box
- Iper-V 
- Parallel OS
