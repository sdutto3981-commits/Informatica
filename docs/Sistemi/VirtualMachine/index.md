# Macchine virtuali

Una macchina virtuale (VM) simula un computer mediante software. Consente di eseguire un sistema operativo guest isolato rispetto al sistema host, entro i limiti configurati dall'hypervisor.

- [Che cos'è una macchina virtuale](Che%20cos'è%20una%20Virtual%20Machine.md)
- [Creazione di una macchina virtuale](Creazione%20Macchina%20Virtuale.md)

Prima di creare una VM scegli immagine ISO, quantità di RAM e CPU, dimensione del disco virtuale e tipo di rete. Non assegnare alla VM tutte le risorse del computer host. Gli snapshot consentono di tornare a uno stato precedente, ma non sostituiscono un backup indipendente.
