# Creazione Macchina Virtuale

Immagine del sistema operativo come Windows Linux MacOS l'ISO ci serve per masterizzare su un supporto fisico oppure per montare l'immagine direttamente in una virtual machine.

In altri casi possiamo anche trovare un unita avviabile che può essere una chiavetta o un disco avviabile con all'interno già il contenuto ISO e file di avvio corretti si può quindi avviare la macchina direttamente da usb senza installare il sistema operativo
