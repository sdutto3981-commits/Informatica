# Sistemi a processore

Un sistema di elaborazione corrisponde spesso ad un sistema a processore che collega anche periferiche di input ed output.

I sistemi si elaborazione delle informazioni sono particolarmente vantaggi in termini di:
- Velocità
- Dimensione in termine di memoria
- Affidabilità
- Costo
