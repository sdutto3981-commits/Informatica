# Memorie a semiconduttore

La memoria centrale di un sistema di elaborazione è realizzata con la tecnologia a  semiconduttore.

Le memorie a semiconduttore sono di due tipi:
- Le memorie volatili: conservano i dati finché il chip è alimentato. Le **memorie volatili a semiconduttore** costituiscono la memoria centrale. Rientra in questa categoria la RAM che può essere: **DRAM** o **SRAM**
- Le **memorie non volatili o permanenti**: conservano i dati anche in assenza di alimentazione elettrica. Esse sono utilizzate per integrare nel hardware chip che contengono firmware oppure per i programmi di sistema come il BIOS nella ROM
