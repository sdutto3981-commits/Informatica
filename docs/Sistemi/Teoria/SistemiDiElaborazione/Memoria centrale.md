# Memoria centrale

- Dimensione relativamente limitate
- Accesso molto rapido
- E composta da:
	- RAM Random Access Memory è volatile usata per memorizzare dati e programmi
	- ROM Read Only Memory è persistente ma il suo contenuto è fisso e immutabile usato per memorizzare i programmi di sistema
