# Processori multi core

Dal momento che è difficile aumentare indefinitamente le prestazioni di un singolo processore, negli ultimi anni si sono introdotti multi core che integrano in un unico dispositivo più processori.

Esempi:
- CELL 
- Ultra SPARC Sun
- Phenom AMD
- Core i7 Intel 
- Tegra 3  Invidia
