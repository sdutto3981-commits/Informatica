# Memoria ROM

Con il termine ROM Read Only Memory indichiamo una categoria di memorie accessibili sono in lettura.

Attualmente esistono particolari ROM che possono essere anche riscritte.

In ogni caso tutte le ROM sono caratterizzate dal fatto che le informazioni in esse contenute permangono anche quando manca corrente.

La memoria ROM vengono in genere utilizzare per memorizzare programmi e i dati di configurazione essenziali iper il funzionamento del computer.

Esistono diversi tipi di ROM.

**ROM non programmabili:**
- Esse vengono prodotte già inglobando il programma o i dati.

**PROM Programmable ROM:**
- Normalmente sono vuote al loro interno e possono essere programmate successivamente attraverso appositi programmatori di PROM tuttavia non possono essere più modificate nel contenuto

**EPROM Erasable Programmable ROM:**
- Normalmente sono vuote al loro interno possono essere programmate ma a differenza delle PROM la programmazione può avvenire più volte la vecchia programmazione può essere cancellata tramite raggi UV

**EEPROM Eletrical Erasable Programmable ROM:**
- Sono identiche alle EPROM per la cancellazione al posto che avvenire tramite raggi UV avviene tramite energia eletricca
