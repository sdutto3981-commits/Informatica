# Compilatori Linux

GCC = GNU COMPILER COLLECTION
permette di eseguire file in codice creati tramite un editor 

`sudo apt install build essential`

PASSI:
- creare un file in linguaggio C, tramite editor
- salvare il file.c
- compilare il file con il comando: `gcc file.c -o file`
- eseguire il file ./file
