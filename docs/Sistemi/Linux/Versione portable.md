# Versione portable

Nelle versioni portable non abbiamo una modifica il registro di sistema non richiede un installazione piò essere eseguita da qualsiasi posizione.

Per l'installazione di un pacchetto nella versione portable dobbiamo usare il comando
```
pacman -S nano
```

`pacman` manager di pacchetti e piìoi `-S` ed infine il nome del pacchetto `nano`
