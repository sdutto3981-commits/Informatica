# Editor NANO Linux

Avvio e salvataggio
Apri o crea un file `nano nomefile.txt`
Salva file Ctrl + O
Conferma nome file Invio
Esci da Nano Ctrl + X
Esci senza salvare Ctrl + X, poi N

Movimento nel testo
Sposta cursore Frecce
Inizio riga Ctrl + A
Fine riga Ctrl + E
Vai a una riga specifica Ctrl + _ (underscore)
Mostra posizione cursore Ctrl + C

Copia, taglia e incolla
Taglia riga o selezione Ctrl + K
Incolla testo Ctrl + U
Inizia/termina selezione Ctrl + ^ (Ctrl + Shift + 6)

Cerca e sostituisci
Cerca parola Ctrl + W
Ripeti ricerca Alt + W
Trova e sostituisci Ctrl + \

File e inserimenti
Inserisci altro file Ctrl + R
Inserisci output comando Ctrl + R, poi Ctrl + T

| Utilità e impostazioni         |                 |
| ------------------------------ | --------------- |
| Aiuto (lista comandi)          | Ctrl + G        |
| Giustifica paragrafo           | Ctrl + J        |
| Mostra/nascondi numeri di riga | Alt + Shift + 3 |
| Annulla ultima azione          | Alt + U         |
