# Data types C

In C ritroviamo diversi tipi di dati:
- int: numeri interi
- float: numeri in virgola mobile con precisione singola 32 bit
- double: numeri in virgola mobile con precisione doppia 64 bit
- char: carattere

Non abbiamo la tipologia: string ne bool
