# Grandezze eletriche

Le tre grandezze fondamentali in un circuito sono: 
- Tensione
- Corrente
- Resistenza

|Grandezza|Simbolo|Unita di misura|Significato|
|-|-|-|-|
|Tensione|V|Volt (V)|Differenza di ponteziale tra due punti|
|Corrente|I|Ampere (A)|Quantità di carica che attraversa una sezione nell'unità di tempo|
|Resistenza|R|Ohm (Ω)|Opposizione al passagio di corrente|
