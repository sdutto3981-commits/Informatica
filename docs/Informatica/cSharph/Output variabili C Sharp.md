# Output variabili C Sharp

Possiamo usare la funzione `WriteLine()` per avere in output delle variabili possiamo eseguire questa operazione in vari modi:

Usando il carattere +
```C#
string name = "Stefano";
Console.WriteLine("Hello "+name);
```

Possiamo anche usare il carattere + per unire due variabili
```C#
string name = "Stefano ";
string lastname = "Dutto";
string fullName = name + lastname;
Console.WriteLine(fullName);
```

Mentre per  valori numeri il segno + funziona come operatore matematico
