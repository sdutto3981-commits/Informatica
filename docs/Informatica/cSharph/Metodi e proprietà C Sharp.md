# Metodi e proprietà C Sharp

I metodi sono delle funzioni predisposte dal linguaggio di programmazione che ci permettono di svolgere determinate azioni 

Le proprietà sono delle azioni che possiamo applicare ai tipi di dato.

La differenza principale dei due sono che nel primo caso dobbiamo usare le parentesi tondo siccome dobbiamo inserire dei parametri rispetto al metodo mentre le proprietà non ci sono le parentesi tonde
