# Istruction Set Architetture ISA

- I processori sono organizzati in famiglie
- I processori di una stessa famiglia sono compatibili a livello software
- La compatibilità si ottiene adottando una stessa Istruction Set Architetture (ISA) corrisponde all'insieme di informazioni relative al processore usate dal programmatore

Quindi il sistema operativo permette la comunicazione tra l'utente e il device
