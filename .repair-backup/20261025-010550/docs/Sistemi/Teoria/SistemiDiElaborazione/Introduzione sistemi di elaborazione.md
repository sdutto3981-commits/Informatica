# Introduzione sistemi di elaborazione

Un sistema di elaborazione è un sistema in grado di
- Ricevere informazioni dall'esterno
- Elaborare queste informazioni

I sistemi di elaborazione dono principalmente basati su:
- Tecniche per rappresentare delle informazioni
- Tecniche per definizione della sequenza di operazioni ossia di algoritmi  necessaria per risolvere un problema
- Tecniche per la memorizzazione dei dati e l'automazione delle operazioni
