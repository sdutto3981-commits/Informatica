# Paragrafi HTML

L'elemento paragrafo viene definito dal tag `<p>` ogni paragrafo va sempre a capo i browser in automatico aggiungono un margine

#### Visualizzazione HTML

Per quanti spazio invii io inserisca nel editor la visualizzazione sul browser non ne risente a meno che usi comandi specifici come `<br>` per andare a capo

#### Regole orizzontali HTML

Il tag `hr` crea un interruzione tematica ovvero una riga orizzontale

```html
<h1>This is heading 1</h1>
<p>This is some text.</p>
<hr>
<h2>This is heading 2</h2>
<p>This is some other text.</p>
<hr>
```

non ha un tag di chiusura

#### Interruzione di riga HTML

Il tag `<br>` break line interrompe la riga dove viene posizionato ovvero va a capo

#### Testo pre formattato HTML

Utilizzando il tag `<pre>`  il testo all'interno visualizzato in un font a larghezza fissa e conserva sia spazi che gli invii

```html
<pre>
  My Bonnie lies over the ocean.

  My Bonnie lies over the sea.

  My Bonnie lies over the ocean.

  Oh, bring back my Bonnie to me.
</pre>
```

Verrà visualizzato uguale
