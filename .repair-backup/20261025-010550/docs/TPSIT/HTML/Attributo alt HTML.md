# Attributo `alt` delle immagini

L'attributo `alt` fornisce un testo alternativo per le immagini. È usato dalle tecnologie assistive e può essere mostrato quando l'immagine non è disponibile.

```html
<img src="grafico.png" alt="Vendite in crescita dal primo al quarto trimestre">
```

- Se l'immagine trasmette informazioni, descrivi in modo conciso il contenuto o la funzione rilevante.
- Se è puramente decorativa e non aggiunge informazioni, usa `alt=""`.
- Se l'immagine è l'unico contenuto di un link, il testo alternativo dovrebbe spiegare la destinazione o l'azione.
- Evita testi generici come “immagine” o la ripetizione di una didascalia già vicina, quando non aggiunge valore.

`alt` non è un tooltip: per informazioni supplementari usare contenuto visibile e appropriato, non affidarsi soltanto a un attributo.
