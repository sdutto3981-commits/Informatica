# Bordi CSS

La proprietà `border` definisce il bordo di un elemento. Può specificare larghezza, stile e colore.

```css
.card {
  border: 1px solid #777;
  border-radius: 0.5rem;
}
```

Proprietà utili: `border-width`, `border-style`, `border-color` e `border-radius`. Se `border-style` è `none`, il bordo non viene visualizzato anche se larghezza e colore sono impostati.

Questa pagina è un promemoria delle proprietà CSS, non un elemento HTML. Per il modello completo consulta [box model](../CSS/Box-Model.md).
