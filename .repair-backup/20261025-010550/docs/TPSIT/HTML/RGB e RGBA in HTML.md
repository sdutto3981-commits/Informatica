# RGB e RGBA in HTML

RGB rispettivamente red green e blue

RGBA rispettivamente RGB con un canale alpha (opacità)

#### RGB

Possiamo specificare un colore usando il valore RGB con la seguente formula:
`rgb(red, green, blue)`
Ognuno di questi parametri a valore da 0  a 255

#### RGBA

Possiamo specificare un colore usando i valore RGBA con la seguente formula:
`rgba(red, green, blue, alpha)`
Il parametro alpha ha valori da 0.0 totalmente trasparente a 1.0 per niente trasparente
