# Repository GitHub

Cos' una repository  un elemento fondamentale di github serve per lasciare tutto il codice per il progetto

Quando accediamo al profilo di GitHub possiamo crare una nuova cartella dobbiamo inserire un nome alla cartella poi scegliere una descrizione e se rendere questa cartella pubblica o privata.

Successivamente possiamo scegliere di aggiungere un READNE ovvero un file che gli utente andranno a leggere per capire cosa tratta il progetto.

Cosa sono le licenze e quali scegliere esse dicono agli altri utenti cosa possono fare con il tuo codice .

Come glia altri utenti interagiscono con il mio  codice in base alla licenza che decido di usare possono fare diverse cose ma principalmente andranno a costruire sul mio codice i loro personali progetti o lo modificheranno.

Cos'è un .gitignore serve per far si che git ignori certi file e certe cartelle guardare:
- gitignore.io

La schermata della mia cartella presenza diverse diapositive come per esempio:
- Issues: Dove possiamo trovare task oppure bug del codice
- Pull requests: Dove vediamo chi scarica la cartelle del codice
- Wiki: Dove si puo mettere eventuale documentazione ecc...
- Setting: Dove possiamo aggiungere eventuali collaboratori al  nostro progetto

E possivie aumentare le proprie conoscenza su GitHub Foundations
