# Sistemi combinatori

Un circuito combinatorio non conserva uno stato: a ogni combinazione degli ingressi corrisponde una combinazione di uscite. Il comportamento si rappresenta tramite tabella della verità ed espressioni booleane.

## Metodo per risolvere un esercizio

1. Definisci le variabili di ingresso e di uscita.
2. Costruisci la tabella della verità.
3. Ricava la funzione logica per ogni uscita.
4. Semplifica con l'algebra booleana o con le mappe di Karnaugh, secondo quanto richiesto.
5. Disegna il circuito usando porte logiche.
6. Verifica la soluzione confrontando tutte le combinazioni degli ingressi.

Gli argomenti di laboratorio possono includere la simulazione in LabVIEW e la realizzazione di circuiti con gli strumenti indicati dal docente.
