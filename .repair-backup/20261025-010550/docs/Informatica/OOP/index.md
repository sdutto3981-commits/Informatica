# Programmazione orientata agli oggetti in C#

La programmazione orientata agli oggetti (OOP) organizza il codice intorno a **oggetti**, che combinano stato e comportamento. In C# gli oggetti sono istanze di classi; i principi più importanti sono incapsulamento, astrazione, ereditarietà e polimorfismo.

## Regole di progettazione

- Una classe deve avere una responsabilità chiara.
- Mantieni i dati interni privati e fornisci operazioni controllate.
- Preferisci la composizione all'ereditarietà quando non esiste una vera relazione “è un”.
- Usa interfacce per descrivere capacità o contratti comuni.
- Evita gerarchie profonde e classi con troppe responsabilità.
- Scrivi codice di esempio compatibile con la versione .NET configurata nel progetto scolastico.
