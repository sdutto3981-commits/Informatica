# Algoritmi fondamentali

Un algoritmo è una sequenza finita e non ambigua di istruzioni che trasforma dati di ingresso in un risultato.

## Metodo per un esercizio

1. Identifica input, output e vincoli.
2. Scrivi i casi normali, limite e non validi.
3. Scegli strutture dati e controlli di flusso.
4. Descrivi i passaggi con pseudocodice o diagramma a blocchi.
5. Traccia l'esecuzione con valori di esempio.
6. Valuta la correttezza e, quando richiesto, il numero di operazioni.

Per la ricerca binaria l'array deve essere ordinato; la ricerca lineare, invece, può essere usata anche quando l'array non è ordinato.
